snmp_lldp_check.py : takes a list of devices as input and checks for SNMP and LLDP on those devices.

mac_find.py : Python script to ping IPs, retrieve their MAC addresses via ARP, and export IP-MAC mapping to text and CSV files. 
  use when mac address needed for a bunch of IP.
  
Merger.py : Merge list of ip stored in txt file, sort them, and export a combined IP→Name list to an Excel file.
  use to merge a list of ip from various sources like dhcp list or nmap scan or advanced ip scanner.

mac_matching.py : search a list of mac address from a pdf file.
  use to search a list device using mac address from a scan saved in pdf
